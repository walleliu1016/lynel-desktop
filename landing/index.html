使用指南

几分钟即可上手

从安装到远程控制，六步走完。

1

下载安装

macOS 将 App 拖入「应用程序」，首次运行需执行 xattr -cr 移除隔离属性；Windows 双击安装；Linux 赋予可执行权限后运行。

2

首次使用

启动后设置本地账户密码并登录，应用自动加载所有历史会话。

3

新建会话

选择项目目录，挑选 Agent：Claude Code / Codex / OpenCode / OMP / DeepSeek Harness，即可开始。

4

开始对话

在终端输入消息回车即可。实时查看会话状态与请求追踪（Trace），随时切换历史会话。

5

远程控制

绑定企业微信 Bot 或使用手机 App，离开工位也能收发消息、审批权限、查看进度。

6

控制指令

远程发送 /interrupt 或 /ctrl-c 可中断当前生成，/screenshot 可截取终端画面。

FAQ

常见问题

支持哪些 Agent？

Claude Code、Codex、OpenCode、OMP，以及内嵌的 DeepSeek Harness Web 界面。

我的本地会话会被上传吗？

会话数据默认本地存储；仅在你配置并开启云服务时，才按需上行同步。

如何远程控制？

绑定企业微信 Bot 后，可在手机端收发消息、审批权限、查看进度。
