# Lynel Desktop 使用指南

> 适用版本：v0.0.22 及以上。文中图片占位为 `guide-images/<文件名>`，请将实际截图放入本文件同级的 `guide-images/` 目录（文件名即建议命名）。

## 一、这是什么？

Lynel Desktop 是一个**跨平台的多 Agent 会话管理桌面应用**。简单说，它把 Claude Code、Codex、OpenCode、OMP 这些「在终端里干活的 AI 编程助手」装进一个本地窗口，让你用图形界面同时管理多个会话、随时查看运行状态和请求明细，还能通过**企业微信**在手机上远程收发消息、审批权限。

核心能力：

- **多 Agent**：一个应用同时驾驭多个 AI 编程助手，互不干扰。
- **多会话**：同时开多个会话，各自独立运行，随时切换。
- **全程可视化**：每个会话都带有「Trace」页，展示每一次 API 请求（模型、延迟、费用、Token）。
- **远程协作**：绑企业微信机器人后，手机上就能查看进度、发任务、审批权限。

## 二、安装与启动

从 **GitHub Releases 页面**下载对应平台的安装包（支持 Windows / macOS / Linux）。

### Windows

下载 `.exe` 安装程序，双击运行，按向导完成安装即可。

### macOS

1. 下载 `.dmg` 文件，挂载后把 `Lynel Desktop.app` 拖入「应用程序」文件夹。
2. 因为应用未做 Apple 代码签名，首次打开可能被系统拦截。两种解决方式任选其一：
   - **命令行**：打开终端执行 `xattr -cr /Applications/Lynel\ Desktop.app`；
   - **图形界面**：首次被拦截后进入「系统设置 → 隐私与安全性」，在「安全性」里找到「已阻止使用『Lynel Desktop』」，点击「仍要打开」。
3. 之后即可正常启动，无需重复操作。

### Linux

1. 下载 `.AppImage` 文件。
2. 赋予可执行权限并运行：
   ```bash
   chmod +x lynel-desktop-<版本>-x64.AppImage
   ./lynel-desktop-<版本>-x64.AppImage
   ```
3. 部分系统可能需要安装 `fuse`：
   ```bash
   sudo apt install fuse   # Ubuntu / Debian
   ```

> **提示**：点击窗口关闭按钮并不会退出程序，而是**隐藏到系统托盘**，会话不会中断。需要完全退出时使用托盘菜单。

## 三、登录与云服务

首次启动会进入登录页。

1. **用户名**：输入你的 UM 账户名。
2. **启用云服务**（可选）：打开「启用云服务」开关，填写**服务地址**，并在「密码」处填写 **PIN + Token**。
   - 开启云服务后，会话消息与权限请求会**实时推送到移动 App**，方便远程审批与查看进度。
   - 关闭云服务时，只用用户名即可登录（不做云端校验）。
3. 点击**登录**进入主页。

登录页右下角还有「设置」按钮，可在登录前调整配置。

![登录页](guide-images/00-login.png)

## 四、界面总览

当前是**两栏布局**：左侧是功能入口与会话列表，中间是内容区（标签页）。

```
┌──────────┬──────────────────────────────┐
│ 左侧栏     │ 中间内容区                     │
│ 入口+会话  │ 标签页（首页/会话/设置/指南/…）  │
└──────────┴──────────────────────────────┘
```

- **标题栏**：左侧显示正在运行的会话数量；右侧有**使用指南**、**设置**、**退出登录**等入口（Windows 上窗口控制按钮在右上角）。
- **左侧栏**（可折叠成窄栏）：
  - 顶部：收起按钮 + **云服务连接状态**；
  - 入口按钮：**首页** / **DeepSeek Harness** / **搜索**；
  - 中间：**会话列表**；
  - 底部：账户信息 + **使用指南** + **设置**。
- **中间内容区**：首页、各个会话、设置、使用指南、DeepSeek Harness 分别以标签页打开，可随时切换。每个会话标签页内部还有「**终端** / **Trace**」两个子页。

![主界面总览](guide-images/01-overview.png)

> 右上角还有一个常驻的 ASCII 电子宠物 Buddy（纯装饰，不影响功能；设置里对应菜单暂未开放）。

## 五、Agent（AI 编程助手）入门

### 支持的 Agent

| Agent | 说明 |
|-------|------|
| **Claude Code** | Anthropic 官方 CLI（默认、始终可用） |
| **Codex** | OpenAI CLI |
| **OpenCode** | SST 开源 CLI |
| **OMP** | oh-my-pi |

### ⚠️ 重要：Agent 启用开关（先看这个）

为了保持简洁，**默认只有 Claude Code 可用**。要使用 Codex / OpenCode / OMP，需要先到 **设置 → 通用** 打开对应的「Agent 启用」开关：

- 打开后，该 Agent 才会出现在「新建会话」的下拉、会话列表等处。
- 关闭后，该 Agent 的**历史会话会被隐藏**，也无法新建它的会话。

![Agent 启用开关](guide-images/07-agent-path.png)

### 指定 Agent 可执行文件路径

到 **设置 → 通用 → Agent 可执行文件路径**，每个启用的 Agent 对应一行输入框，填写完整路径；留空则自动查找系统 PATH。

### DeepSeek Harness（独立面板）

左侧栏的 **DeepSeek Harness** 入口会打开一个独立的 Harness 面板（在浏览器式页面里运行 DeepSeek），它不是会话 Agent：

- 需要先全局安装 dsh：`npm i -g @deepseek-ai/dsh`（版本由你用 npm 管理）。
- 首次打开自动启动 dsh 服务，加载成功前显示「正在启动…」；未安装会提示安装命令。

![DeepSeek Harness 入口](guide-images/09-dsh-entry.png)

## 六、创建并管理会话

### 新建会话

**方式一（首页快速输入）**：在首页输入框里输入第一条提示词，选择 Agent、可选工作目录与要绑定的机器人，回车或点发送即可创建并运行。

**方式二（新建对话框）**：点击「新建」按钮打开「打开 Session」对话框，它有两个子页：

- **历史会话**：从已有历史会话中直接打开/恢复；
- **打开新目录**：填写表单新建——选择**工作目录**（默认用户主目录）、**Agent 类型**、可选**提示词**；Claude 还可勾选附加参数（`--verbose` / `--debug`）；可选**绑定机器人**。其他 Agent 暂不支持附加参数。

![新建会话对话框](guide-images/02-new-session.png)

### 会话列表与状态

左侧列表实时展示所有会话，每条显示 **Agent 徽标**、标题、最近活跃时长、状态点；已绑定机器人的会话带 bot 图标。状态含义：

| 状态点 | 含义 |
|--------|------|
| 灰色 | 空闲（idle） |
| 蓝色转圈/点亮 | 运行中（思考、输出或执行工具） |
| 红色闪烁 | 等待授权 |
| 绿色 | 已完成 / 已结束 |

列表支持**搜索**；也可以把整个左侧栏折叠成窄栏给终端腾空间。

### 打开 / 恢复历史会话

之前创建过的会话（包括直接在命令行里使用 Agent 产生的会话）都会出现在列表里。点击即可打开：Lynel Desktop 会自动以恢复模式启动对应 Agent，**完整保留之前的对话上下文**。

### 右键菜单

在会话条目上右键（或悬停 1 秒查看详情浮层），可以：

- **重命名**：给会话起个好记的名字。
- **复制 Session ID**：用于企业微信精确指定会话。
- **绑定 Bot / 切换 Bot / 解除绑定**：把一个企业微信机器人绑定到该会话（详见企业微信章节）。

![会话右键菜单](guide-images/05-session-menu.png)

### 多会话并行

每个会话是独立的标签页和独立的 Agent 进程，可以同时运行多个互不干扰。标签页会实时反映状态，运行中的会话还可以随时切到它的 **Trace** 子页查看请求明细。

### 在终端中与 Agent 对话

会话标签页的「终端」子页是一个完整的交互式终端：

- 直接输入文字，**按回车发送**（没有回车 Agent 不会执行）。
- Agent 弹出的选择菜单、权限确认等，用**方向键 + 回车**操作。
- 终端内 **`Ctrl + 滚轮`** 实时调节字号；**右键**菜单可复制 / 粘贴 / 全选。
- 点击终端里的链接会用系统浏览器打开。
- 想中断 Agent 当前输出，按 `Ctrl+C`。

![会话终端运行中](guide-images/03-terminal.png)

## 七、Trace：请求全链路可视化

每个会话标签页都有「**终端 / Trace**」两个子页，切到 **Trace** 查看该会话的每一次 API 请求，方便理解"AI 每一步到底调用了什么、花了多少钱"。

Trace 面板结构：

- **顶部工具栏**：请求总数、**总费用**、刷新按钮；支持按模型过滤、只看错误请求。
- **左侧请求列表**：每条显示状态、模型、Token 用量、延迟。
- **右侧详情**：点击某条请求，在右侧展示完整的请求-响应内容。

列表默认加载最近 50 条，向上滚动加载更早记录。数据保存在 `~/.lynel-desktop/projects/<项目>/<会话>/` 下，随时可查。

![Trace 面板](guide-images/08-trace.png)

## 八、权限审批

Agent 执行敏感操作（运行命令、写文件等）前会请求授权。Lynel Desktop 把权限请求同步到多个入口，方便你在任何地方处理。

当会话进入「等待授权」状态时：

- 左侧会话列表该条变为**红色闪烁**；
- 会话标签页图标变为警示样式；
- 如果绑定了企业微信机器人，会同时推送一张**交互式权限卡片**；
- 主窗口会闪烁 / 弹出通知提醒你处理。

![等待授权状态](guide-images/06-awaiting-permission.png)

任选一种方式处理，各处会自动同步：

**方式一：在终端里处理** — 像命令行一样，用方向键选择「允许 / 拒绝」后回车。

**方式二：在企业微信里处理** — 收到交互式卡片，直接点按钮：

- **普通权限请求**：允许 / 拒绝按钮；
- **选择题**：单选 / 多选，选完点「提交」；
- **多个问题**：逐题发送卡片，答完一道自动发下一道，全部答完自动回复 Agent；
- **退出计划**：Agent 计划退出时会推送确认卡片。

在终端自行处理后，企业微信会收到「权限已在终端处理」的通知，不会重复审批。

![企业微信权限卡片](guide-images/17-wecom-permission-card.png)

## 九、企业微信集成

配置企业微信机器人后，可以在手机上远程查看 Agent 的工作进度、发送新任务、处理权限请求。

### 第一步：在企业微信里创建机器人

1. 进入机器人管理页面，**创建一个新的智能机器人**。
2. 编辑机器人 → API 配置 → **使用长链接**，创建完成后记录两项信息：
   - **Bot ID**：机器人的唯一标识；
   - **Secret**：调用密钥（注意保密，不要泄露）。

![创建企业微信机器人](guide-images/15-wecom-create-bot.png)

### 第二步：在 Lynel 里添加机器人

打开 **设置 → 机器人**，点击「添加 Bot」，填写：

- **名称**：任意标识，如"我的助手"；
- **来源**：选择"企业微信"；
- **Bot ID** 与 **Secret**。

保存后机器人会自动连接，状态点变为**绿色**即表示已连接。

![机器人管理](guide-images/21-bot-management.png)

### ⚠️ 第三步：先给机器人发一条消息

**刚创建的机器人，必须在企业微信里先给它发一条消息**（如 `/help`），建立会话后它才能正常向你推送消息。这是最常见的新手卡点——没发过消息前，机器人可能收不到 / 推不出东西。

### 第四步：把机器人绑定到会话

一个机器人只能绑定一个会话，一个会话也只能绑定一个机器人。三种方式：

- **新建会话时**：在新建对话框 / 首页输入框的「Bot」下拉里选择。
- **已有会话**：右键会话 → **绑定 Bot** → 在列表中选择。
- **还没有机器人？** 在绑定 Bot 的列表底部点「**＋ 去添加**」，弹窗里直接填写机器人信息，保存后自动绑定到当前会话。

![右键绑定机器人](guide-images/23-session-context-bind-bot.png)

### 解绑与删除

- 在 **设置 → 机器人** 里，对已绑定的机器人点「解绑」即可解除绑定关系。
- 删除机器人时会自动解绑其关联的会话。

### 引用消息快捷回复

不需要输入任何命令，就能向指定会话发消息：

1. 长按机器人发送的任意消息，选择「**引用**」；
2. 直接输入要发给 Agent 的内容；
3. 系统自动从被引用消息的头部解析会话，把内容转发过去。

每条机器人消息都自带头部（`**项目名** · 会话#N · 会话ID` + 时间），多个会话交错时也能分辨。若给**未绑定会话**的机器人发消息，会收到提示「当前没有绑定会话，请先绑定一个会话」。

### 控制指令

在企业微信里发送以下命令可**远程操控终端进程**（不会转发给 Agent）：

| 命令 | 效果 |
|------|------|
| `/interrupt`、`/ctrl-c`、`/ctrl+c` | 中断 Agent 当前生成（等同终端按 Ctrl+C） |
| `/escape`、`/esc` | 发送 Esc 键 |
| `/ctrl-d` | 发送 Ctrl+D（EOF） |
| `/ctrl-z` | 发送 Ctrl+Z（SIGTSTP） |
| `/screenshot` | 截取当前终端画面，以 PNG 图片发送 |
| `/help` | 查看可用指令 |

**典型场景**：Agent 陷入死循环 / 输出过长 → `/interrupt`；想看终端当前状态 → `/screenshot`。

### 推送内容与角色标识

绑定后，企业微信会收到：会话启动通知、你的提示词、Agent 回复、工具调用、权限请求卡片、工具执行结果、截图。是否推送「思考过程」和「工具调用」可以在 **设置 → 通用** 里关闭（只影响推送，不影响终端显示）。

推送消息使用统一格式，消息体前有角色图标：

| 图标 | 含义 |
|------|------|
| 👤 | 用户输入 |
| 🤖 | Agent 回复 |
| 💭 | 思考过程 |
| 🔧 | 工具调用 |
| ✅ / ❌ | 工具执行成功 / 失败 |
| 🔐 | 权限请求 |
| ❓ | Agent 向你提问 |

![企业微信消息格式](guide-images/11-wecom-progress.png)

## 十、模型供应商

在 **设置 → 模型供应商** 里管理各 Agent 使用的 API 供应商，支持配置多个并随时切换，适合在官方 API、代理网关或第三方兼容服务之间选择。

**布局**：左侧是 Agent 菜单（只显示已启用的 Agent），右侧是选中的 Agent 的供应商卡片区。

### 添加与切换

- 点击卡片区右上角「**+**」新增供应商；
- 选中某个供应商后点「**设为当前**」，之后**新启动**的会话将使用该供应商（已在运行的会话不受影响）；
- 当前生效的供应商显示「当前」徽标；
- 供应商可以复制、编辑、删除（至少保留一个）。

### 配置项说明

以 Claude Code 为例：

| 配置项 | 对应环境变量 | 说明 |
|--------|--------------|------|
| Base URL | `ANTHROPIC_BASE_URL` | API 地址，官方为 `https://api.anthropic.com` |
| Auth Token | `ANTHROPIC_AUTH_TOKEN` | 鉴权令牌 |
| 默认模型 | `ANTHROPIC_MODEL` | 未细分场景时使用的模型 |
| Haiku / Sonnet / Opus 默认模型 | `ANTHROPIC_DEFAULT_*_MODEL` | 留空则使用默认模型 |
| 推理模型 | `ANTHROPIC_REASONING_MODEL` | thinking / extended thinking 场景专用 |

不同 Agent 的配置字段略有差异（如 Codex 需要 Provider 名、OMP 用 DeepSeek 网关），按界面提示填写即可。填好 Base URL 后点**测试连接**，可先验证地址与令牌可用再保存。

![供应商设置](guide-images/14-provider-settings.png)

> 注意：供应商配置在**新启动的会话**上生效。已运行的会话仍用启动时的配置，重新打开会话即可切换。

## 十一、设置详解

通过标题栏的**设置**按钮进入。左侧标签依次为：

### 通用

- **Agent 启用**：Codex / OpenCode / OMP 各自的启用开关（见第五章）。
- **Agent 可执行文件路径**：每个启用的 Agent 一行，配置可执行文件完整路径，留空自动查找 PATH。
- **自动锁定**：无操作多久后自动锁定。
- **开关项**：

| 开关 | 说明 |
|------|------|
| 启用日志 | 记录运行日志，排查问题时建议打开 |
| 启动时自启 | 开机 / 登录系统时自动启动应用 |
| 启动时最小化 | 启动后直接最小化到系统托盘 |
| 推送思考过程 | 企业微信推送是否包含 Agent 思考过程 |
| 推送工具调用 | 企业微信推送是否包含工具调用详情 |
| 防止系统休眠 | 有会话运行期间阻止系统休眠，避免长任务被中断 |

### 外观

- **终端配色**：多套配色预设（仅影响终端窗口，不影响 UI 主题）。
- **主题**：浅色 / 深色 / 跟随系统。
- **字体**：字体族、字号（10–24px）、行高。
- **光标**：样式（块 / 下划线 / 竖线）与是否闪烁。
- **行为**：回滚行数。

![外观设置](guide-images/12-appearance.png)

### 云服务

启用开关、服务地址、连接状态（详见第三章）。

### 模型供应商

详见第十章。

### 机器人

机器人列表（状态、名称、来源、Bot ID、绑定会话）、数量阈值、添加 / 编辑 / 删除 / 解绑（详见第九章）。

## 十二、在线升级

在 **设置 → 在线升级** 里可以查看当前版本、手动「检查更新」、下载并安装新版本。

- 应用**首次启动 5 秒后自动检查**，之后每 4 小时检查一次。
- 更新源优先使用 **GitHub Releases**，配置了云服务地址时作为备用源。
- 发现新版本后点「**立即下载**」，可看到下载进度。
- 由于系统签名限制，部分平台下载完成后无法自动安装，安装包会保存到本地并显示路径，点「**打开所在文件夹**」手动安装。
- 如果发布方标记为**必须更新**，会弹出强制更新提示，更新前无法继续使用。

## 十三、数据与日志位置

| 内容 | 路径 |
|------|------|
| 应用配置 | macOS：`~/Library/Application Support/Lynel Desktop/`；Windows：`%APPDATA%\Lynel Desktop\`；Linux：`~/.config/Lynel Desktop/` |
| 网关 / Trace 数据 | `~/.lynel-desktop/projects/` |
| 运行日志 | macOS：`~/Library/Logs/Lynel Desktop/main.log`；Windows：`%USERPROFILE%\AppData\Roaming\Lynel Desktop\logs\main.log`；Linux：`~/.config/Lynel Desktop/logs/main.log` |

日志使用 electron-log 记录，主进程与渲染进程分开写入，滚动保留。排查问题时建议先打开「设置 → 通用 → 启用日志」。

## 十四、常见问题（FAQ）

**如何开启日志或调整企业微信推送内容？**
在「设置 → 通用」里：打开「启用日志」；用「推送思考过程 / 推送工具调用」控制企业微信推送是否包含思考与工具详情。

**刚创建机器人，但企业微信收不到 / 推不出东西？**
先在企业微信里**主动给机器人发一条消息**（如 `/help`），建立会话后机器人才能正常推送。再检查「设置 → 机器人」里是否已添加、Bot ID / Secret 是否正确、是否已绑定目标会话。给未绑定会话的机器人发消息会收到「当前没有绑定会话」的提示。

**终端没有反应怎么办？**
1. 看会话状态：如果是「等待授权」，先处理权限请求；
2. 确认消息以回车结尾——直接在终端输入后按回车即可；
3. 一直停留在加载状态，检查「设置 → 通用 → Agent 可执行文件路径」是否正确（留空用系统 PATH）。

**点了关闭窗口，程序去哪了？**
关闭按钮是**隐藏到托盘**，程序仍在后台运行。点托盘图标可重新打开；要完全退出用托盘菜单。

**历史会话打不开或对话丢失？**
历史会话依赖 Agent 的会话记录文件。若对应工作目录下的记录被清理，将无法恢复上下文，建议重新创建会话。

**切换了模型供应商但没生效？**
供应商配置在**新启动的会话**上生效，重新打开会话即可切换到新供应商。

**会话状态显示不准确？**
状态由本地代理和 hook 事件驱动。长时间不同步时，关闭并重新打开该会话标签页；仍异常则重启应用。
