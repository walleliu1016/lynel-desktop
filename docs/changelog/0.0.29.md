## 0.0.29

### 新功能

- **会话收藏**：任一会话列表项悬停显示星标，点击收藏/取消；收藏数据独立存于 `~/.lynel-desktop/favorite-sessions.json`，不受「最近 30 条」滚动淘汰，也不会上行云端。
- **「打开 Session」改造为打开已有会话**：左侧栏 `folder-open` 现在打开「打开会话」弹窗——顶部为已收藏会话、下方为全部历史会话（含搜索、可点开），右上可跳「新建会话」。
- **收藏四处可见**：收藏的会话在打开弹窗顶部、侧栏「收藏夹」展开区、首页历史（置顶高亮）、顶部搜索（置顶）同步展示；点收藏项即可 resume 打开该会话。
- **新建会话入口收敛**：原「打开 Session」弹窗内的历史会话已并入新弹窗，「新建会话」对话框专注目录新建。

### 修复

- 打开会话类弹窗 Teleport 层级对齐，避免被终端合成层遮挡。
