## 0.0.28

### 新功能

- **明文云凭据文件**：登录成功后把当前 `userId` + `jwt` 明文写入 `~/.lynel-desktop/credential.json`，供本机其他应用读取；登出时删除。凭据变更自动同步该文件。
- **终端文件路径点击**：终端里点击本地文件路径，若指向会话项目目录内的文件，则在「文件」编辑器中以 tab 打开（可多开、可关闭）并自动切到文件页；目录 / 目录外文件维持系统默认打开；http(s) 链接仍走默认浏览器。

### 修复

- 弹窗面板由半透明毛玻璃改为实色，消除覆盖终端时底层文字透出；弹窗内 hover 反馈加深。
- 关闭会话确认弹窗 Teleport 到 body 并提层级，对齐「打开 Session」弹窗，避免被终端合成层压住而透明。
- 凭据文件同步兜底启动恢复早于回调注册的时序：重启登录恢复 token 时正确写入明文凭据文件。
