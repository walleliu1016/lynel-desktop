## 0.0.31

### 新功能

- **定时任务页面重做**：三段式改成「左任务列表 + 右详情」，详情页顶部是工具栏（任务名 / 立即执行 / 溢出菜单）与摘要 chips，**默认打开就展示最近一次运行的完整流水**，不再是空白；从未运行过的任务给引导卡片。运行历史收进工具栏的「历史」按钮，点开是贴着按钮的浮窗（时间轴：状态节点 + 连接线），点某一次即切换正文，不再平铺在详情下方。
- **新建任务改成「模板优先」**：左栏是模板列表（可搜索，分「最近使用 / 我的模板 / 内置」三组），右栏填表单；**「空白任务」置顶且默认选中**。新建 / 复制是两栏，编辑是单栏（内容已在，套模板会覆盖用户改动）。支持把当前内容存成自己的模板（落 `~/.lynel-desktop/task-templates.json`）。
- **执行频率支持三种模式 + 自定义 crontab**：每天（执行时间 + 生效的天 + 生效区间）/ 按间隔（分钟 / 小时 / 天 / 个月）/ 单次执行 / 自定义 crontab。生效的天用 34×34 圆角方片，带工作日 / 周末 / 全选快捷；生效区间可选指定起止日期，区间过了任务自动停用并标「已过期」。时间一律用下拉与点选，不用敲键盘。
- **企业微信支持任务指令**：`/tasks` 列出所有任务（序号 / 名称 / 调度 / 状态），`/run <序号或名称>` 立即执行。走的是与桌面「立即执行」同一个去重入口，手机上连点两次不会起两个进程。
- **任务结果提示按窗口前后台分流**：前台弹右上角浮窗（任务名 / 时间 / 结果，点击直达那次运行），后台弹托盘气泡（macOS / Linux 退回系统通知）。**所有终态都提示，含成功**。
- **任务通知机器人**：设置 → 定时任务里绑定一个机器人，所有任务跑完的结果都推到它（完整正文，不是一行摘要）。它与「机器人」页的会话绑定是两套独立数据，绑定后机器人列表会标出「任务通知」，且**不允许再被会话绑定**（主进程也拦了一道），避免一个 bot 被会话抢走导致任务结果没出口。
- **设置新增「定时任务」菜单**：并发上限（`−/+` 步进）与通知机器人从「通用」里搬出来单独成页。

### 修复

- **任务流水里的最终结果被折叠**：Markdown 默认「超 800 字符 / 18 行」会折成 `> show N lines`，而任务结果经常超过 29 行 —— 想看结果还得先展开。现在流水正文与终局结果永不自动折叠。
- **内嵌 Markdown 的滚动条**：`.markdown-body` 带 `max-height: 460px; overflow: auto`，正文中间会冒出第二条滚动条，滚轮滑到那里会卡一下（嵌套滚动）。去掉，统一交给外层滚动容器。
- **三个弹窗的关闭按钮是空白方块**：`Icon name="x"` 未注册（键名是 `close`），添加机器人 / 扫码创建 / 供应商编辑三处都中招。
- **「扫码创建」点了没反应**：它是模式 tab 而弹窗打开时已是选中态，点它等于点一个已选中的 tab，代码里根本没有「开始生成二维码」这个动作。等待扫码期间现在常驻一个 `[重新生成]`，并有「正在获取二维码…」的占位。
- **「新建任务」按钮没铺满整行**：左栏头部按内容宽度排，右侧留一大片空白，与下面的搜索 / 筛选行右边界也对不齐。
- **任务指令的执行时间**：`claude` 路径解析失败时不再静默 —— 收到任务指令会把原因写进日志。

### 说明

- Windows 上任务进程的 spawn 去掉了 `detached`，消除执行期间频繁弹出的 cmd 闪窗（`DETACHED_PROCESS` 会让 `CREATE_NO_WINDOW` 失效）；杀进程树的 taskkill 也改为带 `windowsHide`。
- 定时任务数据库 schema 升到 v2（新增生效区间两列），老库走 `ALTER TABLE` 自动补齐，不丢数据。
