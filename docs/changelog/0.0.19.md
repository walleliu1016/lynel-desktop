## 0.0.19

### 新功能

- **工具类 hook 批量上报云服务**：`PreToolUse` / `PostToolUse` / `PostToolUseFailure` 三类 hook 事件通过 `desktop:hook:batch` 批量上报云端（攒 50 条立即发，否则 3 秒定时批量发），`PermissionRequest` 仍走审批专用通道，不重复上报。

### 修复

- **下载更新不再误报「Please check update first」**：下载前检查 `checkForUpdates` 结果，仅在存在严格更高版本时才触发 `downloadUpdate`；更新检查改为「新版本严格大于当前版本」才提示，杜绝同版本/降级误报。
- **下载更新解包 reactive Proxy**：前端传入的更新信息解包为纯对象再走 IPC，避免结构化克隆报「An object could not be cloned」。
- **终端处理权限后通知云服务**：用户在终端自行解决权限（PostToolUse 命中取消）时，向云服务发送 `desktop:hook:abort` 清除挂起的权限请求，避免云端一直等待到超时。
- **会话同步字段对齐云端接口**：快照/增量上报的 `SyncSession` 状态字段由 `status` 改为 `state`，与云端 `desktop:session:sync` 新接口字段一致。
