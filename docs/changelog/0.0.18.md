## 0.0.18

### 新功能

- **启动更新气泡提示**：应用启动 5 秒后自动检查更新，发现新版本时在右上角弹一次气泡，点击直达「设置 → 在线升级」下载安装。
- **关闭会话确认弹窗**：关闭运行中会话时，以与现有界面一致的浅色对话框确认，中文警示会话将被终止，支持 `Y` / `Enter` 确认、`N` / `Esc` 取消，替换原生 `window.confirm`。
- **认证事件携带机器名**：`desktop:auth` 认证事件携带 `machine_name`，便于云端多设备识别。

### 修复

- 打开历史会话时弹窗立即关闭进入主界面，PTY / 代理改为后台异步启动，不再等待启动完成才消失。
