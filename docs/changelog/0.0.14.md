## 0.0.14

### 新功能

- **在线升级（auto-update）**：设置页新增"在线升级"tab，支持从 GitHub Releases 或私有 HTTP 云服务检测并下载新版本。
  - **双源 fallback**：优先 GitHub API（`/repos/latest`）获取版本信息，云服务地址已配置时作为 fallback（`/api/update/check?platform=&arch=&version=&channel=stable`）。`latest.yml` 仅作为 sha512 辅助，缺失不阻塞检测。
  - **新模块 `src/main/updater/`**：
    - `checker.ts` — 双源版本检测，GitHub API 10s 超时 + HTTP fallback 10s 超时，失败原因具体到每个源
    - `downloader.ts` — 临时 `latest.yml` → `autoUpdater.setFeedURL(file://)` → `checkForUpdates()` → `downloadUpdate()` → `quitAndInstall()`
    - `index.ts` — 注册 4 个 IPC handler（`app:checkUpdate` / `app:downloadUpdate` / `app:quitAndInstall` / `app:getUpdateStatus`），启动 5s 后首次检查，之后每 4h 定时检查
    - `types.ts` — `CloudCheckResponse`、`CheckResult`、`UpdateState`、`UpdateConfig` 接口定义
  - **新组件 `UpdaterTab.vue`**：显示当前版本、检查更新按钮、更新通道说明、状态/进度/下载/强制更新弹窗。云服务地址复用云服务菜单已有配置，不单独暴露输入框
  - **`electron-builder.yml`** 添加 `publish.github` 配置（`provider: github, owner: walleliu1016`）
  - **仅 stable 通道自动更新**，beta 需手动下载安装

- **权限全局绕过**：每个 session 启动时创建的临时 `settings.json` 自动注入 `"permissions": { "defaultMode": "bypassPermissions" }`，所有 Claude 会话不再弹出权限审批

- **登录错误信息具体化**：`desktopSocket.login()` 返回具体错误原因（网络连接失败、DNS 解析错误、超时、HTTP 401/403/404/5xx、API 返回的 error 字段透传），不再统一显示"请检查用户名和密码"

### 改进

- **企业微信通知**：移除所有消息中的时间戳显示（`HH:mm`），消息更简洁

### 清理

- **删除孤儿文件**：`SettingsView.vue`（Login 场景旧设置页）、`WelcomeView.vue`（已废弃欢迎页）、`wailsjs/` 目录（迁移到 Electron 后的遗留代码）
