## 0.0.30

### 修复

- **Windows 开机自启动后打不开会话**：自启动走 Run 键拉起时进程工作目录为 `C:\Windows\System32`，而 node-pty 对相对 `file` 名会先按进程当前工作目录做 `file_exists('cmd.exe')`，命中即返回空串，上层抛 `File not found: `。改为传 `ComSpec` 绝对路径，不再依赖该解析（可在 System32 下复现：相对名失败、绝对路径正常）。
- **窗口隐藏期间打开文件后文件子页编辑器空白**：Monaco 的行内容（文字 + 行号）由 requestAnimationFrame 调度渲染，窗口隐藏到托盘 / 最小化 / 被遮挡时 Chromium 暂停 rAF，编辑器只建出空壳，且容器尺寸不再变化不会触发 `automaticLayout` 的 ResizeObserver，窗口恢复后无法自愈。现在监听 `visibilitychange` / `focus`，恢复可见时补一次 `editor.layout()` 触发重渲染。
- **侧栏收起态「使用指南 / 设置」上浮到会话列表位置**：收起后会话列表被换成单个图标按钮，侧栏内不再有元素撑满剩余高度；给 `.left-bottom` 加 `margin-top: auto`，展开 / 收起两态都贴底。
- **「打开会话」弹窗搜索词跨次残留**：弹窗常驻挂载，`q` 会保留上次输入，改为每次打开清空。
