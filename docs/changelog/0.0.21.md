## 0.0.21

### 新功能

- **多 Agent 支持**：新增 `AgentKind` 抽象与 `AgentSpec` 注册表（claude/codex/opencode/omp），`createSession` 按 agent 分派启动命令、配置注入与认证提示。
- **新建会话选择 Agent**：新建会话支持下拉选择 agent 类型，选项与各 agent 启动方式联动。
- **Agent 标识展示**：会话列表、终端 tab、历史会话、tooltip 均显示 agent 类型标识（AgentBadge + 配色）。
- **每 agent 可执行路径配置**：GeneralTab 支持为各 agent 单独配置可执行文件路径。
- **ProviderTab 按 agent 分组**：Provider 配置按 agent 分组展示，避免 active 跨 agent 泄漏。
- **codex/opencode 注入与认证检测**：codex 通过 `-c model_providers.<name>.base_url` 覆盖，opencode/omp 通过 env 注入；各 agent 启动时检测认证状态并提示。
- **OpenAI FormatAdapter**：补全 OpenAI Responses/Chat SSE 解析与用量计算。
- **历史会话按 agent 恢复**：点击历史会话按记录的 agent 类型启动（claude 用 `--resume`/`--session-id`，其余 env 注入）。
- **主界面布局重构**：移除独立标题栏，改为三段式布局各列顶部操作行对齐；会话搜索迁移到顶部点击展开；会话列表 / Trace 折叠后完全收起、展开按钮置于内容区上方；Trace 头部重构（折叠按钮保留，请求 / 金额 / 刷新移入控制 tab）；会话列表上方新增 Lynel Desktop 品牌字与版本号。
- **macOS 保留红绿灯**：去掉与红绿灯冲突的 `frame:false`，红绿灯位置与顶部按钮垂直对齐。
- **Buddy 电子宠物**：18 物种预设（含 SHINY 稀有度）与外观/帽子/眼睛/3D 倾斜/浮动幅度定制，支持自定义 ASCII 校验；设置页新增 Buddy 菜单实时预览；欢迎页与会话页常驻陪伴。
- **主题三态**：浅色 / 深色 / 跟随系统，外观设置持久化；终端配色默认跟随 UI 主题。
- **Apple Design UI 重构**：双主题 token 体系（Apple 调色板 + 深色块），登录页/首页/弹窗/Toast/Tooltip 材质化与 hairline 边框，弹簧动效原语（useSpring + SpringTransition + Surface）。
- **首页重设计**：艺术字品牌 + 一句话 tagline + QuickLaunch 快速开会话框（agent/提示词/目录/bot/发送）+ 历史会话仅显示 5 条并可展开收起全部。
- **顶部 tab 栏隐藏首页**：首页移入左侧导航，GlobalTabs 仅保留会话/设置/指南。
- **Agent 图标改用官方品牌 logo**：AgentSelect 下拉与 AgentBadge（会话列表/tab/历史会话）全量替换为官方品牌图标（Anthropic/OpenAI/opencode/oh-my-pi）。
- **会话列表 hover 详情弹窗**：SessionTooltip 恢复并重新设计。
- **工作区信任确认自动接受**：claude/codex 启动时检测信任确认界面并自动回车。
- **创建会话后自动跳转新 tab**。
- **DeepSeek Harness 集成**：左侧边栏新增入口，作为 GlobalTabs 普通 tab 以 iframe 嵌入完整 Web 界面；主进程 `dsh web --port 0` 随机端口启动、解析就绪信号、退出清理；生产将 `@deepseek-ai/dsh` 内置（asarUnpack + `ELECTRON_RUN_AS_NODE`），离线可用。
- **Trace 面板优化**：请求列表逆序显示（最新在上）、加载后默认选中最新一条自动渲染详情、插入时过滤 401 认证失败噪音请求。

### 修复

- 非 claude agent 不再传 claude 专属参数，改用 env 注入本地代理。
- PTY 错误消息按 agent 泛化，不再硬编码 Claude。
- 会话 rebind 写 recents 保留 agent 字段，恢复时能按原 agent 启动。
- 切换 agent 时清空 claude 专属启动选项，防止参数泄漏。
- ProviderTab 非 claude 分组禁用设为当前、删除 provider 后按当前 agent 分组重选。
- GlobalTabs tab badge 尺寸修正。
- dev 模式端口改为 5180，避免与其他本地项目冲突。
- 更新下载重构：自研下载器替代 electron-updater，修复下载失败并补全平台 sha512，进度实时提示。
- 外部通道转发消息分两步写，避免 ink 粘贴检测吞掉回车。
- harness 进程树跨平台清理：用 tree-kill（Windows taskkill /T / POSIX ps 递归）替代只杀父进程，退出时 await 杀净，避免 npx/dsh 子进程残留成孤儿。
- harness iframe 始终挂载避免冻结重载：非激活时 opacity 垫底而非 display:none，切回 tab 不再重新加载页面。
- harness 加载动画 reduced-motion 豁免：系统关闭动画时转圈仍保持旋转。
- Windows 打包版 harness 启动失败修复：安装路径含空格（`...\Programs\Lynel`）时不再走 shell（cmd.exe）spawn，改用 `shell:false` 让 CreateProcess 自动给 argv 加引号，dsh 正常启动。
- Windows 目录选择器崩溃修复（`win32 folder dialog worker exited before reporting a result`）：dsh 的 win32 原生对话框 worker 存在 IPC 竞态/预编译问题，注入 `SSH_TTY` 强制 harness 走内建 browse 后端（纯 Node 目录浏览，不依赖 koffi/原生对话框）；macOS 仍用原生选择器。
- 锁定 `koffi@3.1.2`：win32-x64 预编译二进制自 3.1.3 起损坏（Clang 交叉编译），原生选择器与会话持久化加载即崩；npm `overrides` + pnpm `overrides` 双锁。
