## 0.0.17

### 新功能

- **适配 cloud 会话同步新协议**：`desktop:session:sync` 新增 `mode`（`snapshot` / `event`）与必填 `machine_name`，`status` 收敛为 `open` / `ended`。
- **全量快照兜底**：socket 认证成功后立即发送全量快照；创建/打开/关闭/重命名/删除会话后 500ms 去抖合并再发一次快照，保证 cloud 与 desktop 状态一致。
- **多设备隔离**：会话同步携带 `machine_name`（`os.hostname()`），同一账号多台机器互不覆盖。

### 修复

- 无。
