## 0.0.32

### 新功能

- **终端子页支持右侧文件编辑分屏**：点终端输出里 workdir 内的文件路径，不再跳「文件」子页，而是在终端右侧开出一个**可编辑**的编辑器（多文件 tab、脏标记、Ctrl+S 保存、行内 blame、diff tab），终端不再被整块替换掉 —— 「Claude 改完文件我核对一眼」这个高频动作不用再来回切换。中间拖拽手柄可调右栏宽度（默认 480，钳制 320–900，保证左侧终端至少 400px），右栏头部的 `×` 可收起回终端占满。目录与 workdir 外的路径仍走系统默认程序。
- **分屏展开态按会话记忆**：跟该会话的文件 tab 组一起恢复，宽度全局记忆。右栏与「文件」子页**共用同一份会话级现场**（`openFiles` / `activeRelPath` / 草稿 / diff），所以在哪边打开的 tab 组切过去还是同一组，不是两套状态。切到 Trace / 文件子页时右栏自动让位，切回终端仍是原样。
- **收藏夹支持「以该目录新开会话」**：hover 收藏行出现 `+` 与 `★` 两个按钮，`+` 以该收藏会话的目录起一个**全新空会话**（新 UUID、不 adopt 旧进程、不带旧 sessionId，进去自己敲），点行本身仍是打开原会话。同时收藏行改为**两行**显示（标题 + 目录），目录用左省略保留路径尾部（同项目下路径前缀全一样，截尾等于什么都没说）；两个图标按钮 hover 时浮现并带文字提示（收藏区是滚动容器，提示用 `Teleport` 到 body 才不会被裁）。

### 修复

- **分屏右栏在容器量到 0 宽时不再钳制**：窗口刚加载 / 容器尚未布局时量到的宽度是 0，此前会被当成用户拖动值钳到下限并写回记忆，切回来发现宽度「自己变了」。现在量到 0（或非有限值）时直接跳过，保留用户原有宽度。
- **Git 面板变更列表宽度逻辑并入统一实现**：与代码工作区其他拖宽面板（文件树 / 分屏右栏）改用同一个 `useResizablePanel`，此前是三处各写一份，越界行为已经漂移过（低于下限的用例缺失）。

### 说明

- **全应用同一时刻只允许一个编辑器实例**：`CodeEditor` 以 `file:///${relPath}` 建 Monaco model，而 Monaco 对同一 URI 只允许一个 model，第二个实例直接抛 `Cannot add model because it already exists!`。现在把编辑器区抽成 `FileEditorPanel`，由 `HomeView` 的同一个 computed（`hostInSplit`）驱动两个宿主互斥；分屏右栏那一侧必须用 `v-if`（不能只靠子页的 `v-show`），因为切到 Trace / 文件子页时终端子页只是被隐藏。
- **已知代价**：右栏展开 / 收起、以及「终端 ↔ 文件」子页互切会重建 Monaco 编辑器，**撤销栈（Ctrl+Z）丢失**；文件内容不丢（未保存草稿在 `stores/files.ts` 的 `drafts`，`CodeEditor` 卸载时有意保留）。
- 「文件」子页与 Trace 子页本次不变（Trace 不分屏）。
