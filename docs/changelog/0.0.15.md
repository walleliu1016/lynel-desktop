## 0.0.15

### 新功能

- **VS Code 扩展 `lynel-vscode`（v0.0.15）**：在 VS Code 内嵌入 Claude 交互式终端，复用 Lynel Desktop 的会话、权限、API 代理能力。新增 `vscode-extension/` 目录。
  - **扩展生命周期与状态栏**：`extension.ts` 激活/停用（`onStartupFinished`）、`status-bar.ts` 状态栏、`config.ts` 读取 `lynel.claudeBin` / `lynel.dataDir` 配置
  - **终端能力**：`pty-bridge.ts`（裁剪自 `src/main/pty.ts` 的 node-pty 封装）、`session.ts` 会话管理 + output-batcher、`terminal-manager.ts` Pseudoterminal 多终端创建/销毁与会话恢复
  - **Sessions 会话树视图**：活动栏新增 Lynel 图标 + `lynel.sessions` 树视图，按「运行中 / 历史会话」分组，从桌面端 `~/.lynel-desktop` 读取会话数据（`desktop-data.ts`）；每个会话项提供 3 个 inline 按钮——打开/恢复终端、绑定 Bot、关闭终端
  - **命令集**：`lynel.newTerminal`、`lynel.closeAllTerminals`、`lynel.showSettings`、`lynel.bindWecomBot`、`lynel.manageWecomBots`、`lynel.switchBotBinding`、`lynel.focusTerminal`、`lynel.focusOrResumeTerminal`、`lynel.closeTerminal`、`lynel.bindBotToSession`、`lynel.unbindBotFromSession`
  - **本地 API 代理**：HTTP→HTTPS Claude 流量拦截 + 终端集成，上游地址从 `settings.json` 读取（`apiproxy.ts`）
  - **Hook 服务器 + 权限仲裁器**（`hookserver.ts` / `permission-broker.ts`）
  - **企业微信 Bot 集成**：Bot 绑定/切换/解绑、模板卡片、事件转发（`wecom-manager.ts` / `wecom-channel.ts` / `wecom-cards/`）
  - **CI / 打包 / 调试**：`vsce package` 打包脚本、GitHub Actions 自动打包、F5 启动扩展开发调试（`.vscode/launch.json`）

### 修复

- **openclaw stub 打包失败**：移除 `.vscodeignore` 中 node_modules 排除项，解决 `vsce package` 打包时 openclaw 依赖缺失问题
