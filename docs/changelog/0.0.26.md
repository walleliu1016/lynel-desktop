## 0.0.26

### 新功能

- **macOS 开发者签名 + 公证**：启用 Developer ID 签名与 Apple notarization（hardened runtime + entitlements）。打 tag 发版后 mac 产物经过签名和公证，首次打开不再触发 Gatekeeper「无法验证开发者」警告。

### 优化

- **Bot 绑定/选择交互**：
  - 右键绑定 Bot 浮层与首页 Bot 下拉一致：`去添加` 置顶，高度随机器人数量自适应（不再出现滚动条），已绑定到其他会话的 Bot 名称置灰 + 琥珀「已绑定 xxx」提示。
  - 已绑定/未绑定颜色区分优化：未绑定保持主色可点击，已绑定名称弱化为次级色，一眼区分。
  - 添加机器人弹窗：扫码创建与手动填写 botId/secret 改为二选一（默认扫码），交互更清晰。
  - 设置页新增 Bot 改为弹窗，支持扫码创建，不再使用内联表单。
  - 扫码二维码居中显示修复。
