## 0.0.16

### 新功能

- **会话同步 cloud 增加 `event` 字段**：`desktop:session:sync` 上报的每个 session 新增 `event`，取值 `created` / `opened` / `closed` / `title_updated`，cloud 端可据此做增量更新（建/开/关/标题变更），而非按 `status` 全量覆盖。
- **终端链接用系统默认浏览器打开**：点击 xterm 内的 http/https 链接时，不再新开 Electron 页面，改用系统默认浏览器（`shell.openExternal`）。

### 修复

- **日志文件无法写入**：主进程 ESM 下 electron-log 用裸 `require` 加载抛 `ReferenceError`，一直静默降级到 console，`log_enabled` 开关无效。改为 `createRequire(import.meta.url)` 加载，设置里的日志开关现在真正生效，日志写入 `%APPDATA%\Lynel Desktop\logs\main.log`。
- **CI：tag 发布时把 VS Code 扩展 vsix 上传到 GitHub Release**：`v*` tag 触发的构建会附带上传 `lynel-vscode-<version>.vsix`，方便直接下载安装扩展。
