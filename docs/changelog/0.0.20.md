## 0.0.20

### 新功能

- **多 Agent 支持**：新增 `AgentKind` 抽象与 `AgentSpec` 注册表（claude/codex/opencode/omp），`createSession` 按 agent 分派启动命令、配置注入与认证提示。
- **新建会话选择 Agent**：新建会话支持下拉选择 agent 类型，选项与各 agent 启动方式联动。
- **Agent 标识展示**：会话列表、终端 tab、历史会话、tooltip 均显示 agent 类型标识（AgentBadge + 配色）。
- **每 agent 可执行路径配置**：GeneralTab 支持为各 agent 单独配置可执行文件路径。
- **ProviderTab 按 agent 分组**：Provider 配置按 agent 分组展示，避免 active 跨 agent 泄漏。
- **codex/opencode 注入与认证检测**：codex 通过 `-c model_providers.<name>.base_url` 覆盖，opencode/omp 通过 env 注入；各 agent 启动时检测认证状态并提示。
- **OpenAI FormatAdapter**：补全 OpenAI Responses/Chat SSE 解析与用量计算。
- **历史会话按 agent 恢复**：点击历史会话按记录的 agent 类型启动（claude 用 `--resume`/`--session-id`，其余 env 注入）。
- **主界面布局重构**：移除独立标题栏，改为三段式布局各列顶部操作行对齐；会话搜索迁移到顶部点击展开；会话列表 / Trace 折叠后完全收起、展开按钮置于内容区上方；Trace 头部重构（折叠按钮保留，请求 / 金额 / 刷新移入控制 tab）；会话列表上方新增 Lynel Desktop 品牌字与版本号。
- **macOS 保留红绿灯**：去掉与红绿灯冲突的 `frame:false`，红绿灯位置与顶部按钮垂直对齐。

### 修复

- 非 claude agent 不再传 claude 专属参数，改用 env 注入本地代理。
- PTY 错误消息按 agent 泛化，不再硬编码 Claude。
- 会话 rebind 写 recents 保留 agent 字段，恢复时能按原 agent 启动。
- 切换 agent 时清空 claude 专属启动选项，防止参数泄漏。
- ProviderTab 非 claude 分组禁用设为当前、删除 provider 后按当前 agent 分组重选。
- GlobalTabs tab badge 尺寸修正。
- dev 模式端口改为 5180，避免与其他本地项目冲突。
