## 0.0.34

### 新功能

- **定时任务运行超时可配置**：全局默认值在「设置 → 定时任务 → 单次运行超时」配置，单个任务可在任务表单「超时时间」单独覆盖（默认跟随全局）。预设 15m / 30m / 1h / 8h / 24h 五档 + 自定义（数值 + 分钟/小时，范围 1 分钟 ~ 7 天）。到点自动终止，提示带实际时长（如「超过 2 小时上限，已终止」）；任务详情页仅在覆盖时显示超时标签。老任务自动迁移（不设置 = 跟随全局，默认 30 分钟，行为不变）。

### 说明

- 超时只对之后启动的运行生效，已在跑的运行保持启动时定下的上限；排队超时（30 分钟未启动作废）不受此配置影响。
