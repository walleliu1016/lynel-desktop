## 0.0.23

### 新功能

- **Agent 启停开关**：设置 → 通用 新增 Codex / OpenCode / OMP 启用开关（默认关闭，仅 Claude Code 恒可用）；关闭的 Agent 在新建下拉、路径配置、供应商切换、会话列表与欢迎页全部隐藏，主进程同时拒绝创建其会话。
- **绑定 Bot 支持「去添加」**：会话右键「绑定 Bot」与首页快速输入的下拉中新增「＋ 去添加」，可直接弹窗填写机器人信息并自动绑定到当前会话。
- **全新完整用户指南** `docs/user-guide.md`：面向新用户，覆盖两栏布局、每会话「终端 / Trace」子页、Agent 启用、企业微信集成、VS Code 扩展等全部功能；App 内「使用指南」同步更新。
- **PermissionRequest hook 超时延长至 4 小时**（桌面端与 VS Code 扩展同步），覆盖长时间挂起的权限审批。
- **供应商页改版**：左侧 Agent 菜单 + 右侧供应商卡片区（仅显示已启用的 Agent）。
- **通用设置路径区紧凑化**：Agent 可执行文件路径由 tab 切换改为逐行配置（标签 + 输入框），只开 Claude 时单行紧凑。

### 修复

- **updater 云服务 fallback 与下载流程修复**：云服务地址作为更新源 fallback 时检查与下载更可靠。
- **供应商页左侧菜单激活态去掉 Agent 底色**（原大块底色观感不佳）。
- **通用设置路径标签恢复 Agent logo**：逐行路径配置带 Agent 品牌图标。
