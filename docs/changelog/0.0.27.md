## 0.0.27

### 新功能

- **代码工作区（文件树 + 编辑器）**：会话页第三个子页集成完整文件管理
  - 文件服务：读写 / 新建 / 重命名 / 删除，chokidar 监听外部变更（`file:changed` 事件），IPC 转发层（preload + useElectron）。
  - 文件树：懒加载展开、右键新建 / 重命名 / 删除、按文件类型显示彩色语言图标（vscode-icons 本地 SVG 资产）。
  - Monaco 编辑器：懒加载单例、脏标记 + Ctrl+S 保存、文件 tab、配色跟随终端主题、字号可调。
  - 折叠 / 拖宽：仅收起文件树面板时编辑器保留占满；树面板宽度 240–600px 可拖拽并持久化。
  - 会话现场保留：切换会话时恢复 tab / 草稿 / 激活文件 / 展开态。
- **会话页子页统一图标**：终端 / Trace / 文件各配对应图标；原「代码」子页更名「文件」并换用文件树图标。
- **macOS 公证切换为 App Store Connect API Key（方案 A）**：build.yml 公证凭据由 Apple ID + App 专用密码改为 API Key（`APPLE_API_KEY` / `APPLE_API_KEY_ID` / `APPLE_API_ISSUER`），可独立吊销、可审计。

### 修复

- 文件树递归组件无限递归爆栈。
- 文件读取避免整读大文件；编辑器草稿移入 store；watcher error 防护；快速切文件竞态复查。
- 文件树语言图标 glob 相对路径（`../` → `../../`）。
- 文件管理操作失败时 toast 提示。
- 关闭激活会话时失效现场标记，避免快照被延后 watch 回填。
