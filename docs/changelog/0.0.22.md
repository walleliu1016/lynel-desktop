## 0.0.22

### 新功能

- **Lynel 落地页上线**：新增完整 landing page（Hero、导航、功能亮点、界面展示、FAQ、页脚），平台检测自动匹配下载，移动端 Android/iOS 双端下载入口，VS Code 扩展入口与多平台下载。
- **DeepSeek Harness 改用用户全局安装**：移除内置 `@deepseek-ai/dsh` 依赖及 `asarUnpack`，改为 `npm install -g @deepseek-ai/dsh` + 命令行启动（`dsh web --port 0`），与 claude 一致；支持命令行 `dsh plugin` 管理插件（共享 `~/.dsh` profile），打包体积显著减小。
- **buddy-playground 实验页面**。
- **登录页云服务地址默认填测试地址**。
- **文档更新**：新增通用设置指南；使用指南与当前 UI 对齐；落地页设计文档与实施计划。

### 修复

- **win32 目录选择器还原原生对话框**：移除 `SSH_TTY` hack（全局 dsh 的 koffi 3.1.5 实测可正常加载），目录选择不再走页面内 browse。
- 移除登录页云服务"测试阶段"字样。
- 落地页移动端平台兜底、无 JS 降级、Apple Silicon 架构判断与请求竞态修复。
