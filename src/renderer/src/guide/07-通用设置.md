# 通用设置

在 **设置 → 通用** 中调整 Agent 路径、安全与推送等基础配置。

## Agent 启用

默认只有 **Claude Code** 可用。要使用 Codex / OpenCode / OMP，打开对应的「Agent 启用」开关：

- 打开后，该 Agent 才会出现在新建会话下拉、会话列表等处。
- 关闭后，该 Agent 的历史会话会被隐藏，也无法新建它的会话。

## Agent 可执行文件路径

应用会自动查找系统 PATH 中的 Agent 命令；如果你的 Agent 安装在非标准位置，可在此按 Agent 分别指定：

- 每个**已启用**的 Agent 对应一行（标签 + 输入框），可单独配置路径。
- 输入对应可执行文件的完整路径；**留空则自动查找 PATH**。

## 自动锁定

设置无操作多少分钟后自动锁定应用（重新输入密码），可选 1 / 5 / 10 / 30 / 60 分钟，或关闭。

## 开关项

| 开关 | 说明 |
|------|------|
| 启用日志 | 记录运行日志，排查问题时建议开启 |
| 启动时自启 | 开机 / 登录系统时自动启动应用 |
| 启动时最小化 | 应用启动后直接最小化到系统托盘 |
| 推送思考过程 | 企业微信推送消息时包含 Agent 的思考过程（thinking）；关闭可减少刷屏 |
| 推送工具调用 | 企业微信推送消息时包含工具调用详情（如执行的命令、读写文件）；关闭只保留执行结果 |
| 防止系统休眠 | 有会话运行期间阻止系统休眠，避免长时间任务被中断 |

> 推送思考过程 / 推送工具调用只影响**企业微信推送**的内容，不影响终端内的显示。
