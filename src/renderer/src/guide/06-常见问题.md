# 常见问题

## 如何开启日志或调整企业微信推送内容？

在 **设置 → 通用** 中：

- **启用日志**：开启后记录运行日志，排查问题时建议打开。
- **推送思考过程 / 推送工具调用**：控制企业微信推送时是否包含 Agent 的思考过程与工具调用详情；嫌刷屏可关闭。

各开关的具体说明见"通用设置"章节。

## 终端没有反应怎么办？

1. 查看会话状态：如果是"等待授权"，先处理权限请求（见"权限处理"章节）。
2. 确认消息以回车结尾——直接在终端输入后按回车即可。
3. 如果终端一直停留在加载状态，检查 **设置 → 通用** 中的「Agent 可执行文件路径」是否正确；留空表示使用系统 PATH 中的 Agent 命令。

## 点了关闭窗口，程序去哪了？

关闭按钮是**隐藏到托盘**，程序仍在后台运行，会话不会中断。点击系统托盘图标可以重新打开窗口；需要完全退出时使用托盘菜单。

## 历史会话打不开或对话丢失？

历史会话依赖 Agent 的会话记录文件。如果对应工作目录下的记录被清理，会话将无法恢复上下文，建议重新创建会话。

## 企业微信收不到推送？

1. **先与机器人对话一次**：配置完成后必须在企业微信中主动给机器人发一条消息（如 `/help`），否则机器人无法推送。这是最常见的原因。
2. 检查 **设置 → 机器人** 中机器人是否已添加、Bot ID / Secret 是否填写正确，并已绑定目标会话。
3. 单聊与群聊的 chatId 格式不同：单聊填 userid，群聊填 chatid。
4. 企业微信推送失败不会影响 Agent 正常运行，可查看日志排查。

## 切换了模型供应商但没生效？

供应商配置在**新启动的会话**上生效。已在运行的会话仍使用启动时的配置，重新打开该会话即可切换到新供应商。

## 会话状态显示不准确？

会话状态由本地代理和 hook 事件驱动。如果长时间不同步，可尝试关闭并重新打开该会话标签页；仍异常时重启应用即可恢复。
