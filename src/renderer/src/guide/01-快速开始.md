# 快速开始

Lynel Desktop 是跨平台的多 Agent 会话管理桌面应用：把 Claude Code / Codex / OpenCode / OMP 等终端 AI 助手装进一个本地窗口，用图形界面管理多个会话、随时查看运行状态，还能通过企业微信与手机 App 远程收发消息和处理授权。

## 界面总览

![主界面总览](guide-images/01-overview.png)

- **标题栏**：左侧显示正在运行的会话数量；右侧依次是使用指南、设置和窗口按钮。点击关闭按钮不会退出程序，而是隐藏到系统托盘。
- **左侧会话列表**：展示所有会话及其实时状态，支持搜索和收起。
- **中间标签页**：首页、各个会话、设置分别以标签页打开，可随时切换；会话标签页内是一个完整的交互式终端。
- **右侧 Trace 面板**：实时展示 API 请求列表（状态、模型、延迟、费用），调用链路一目了然。

## 创建第一个会话

1. 在首页点击新建按钮，或点击会话列表顶部的"新建"。
2. 选择工作目录（Agent 将在这个目录下工作）。
3. 挑选要使用的 Agent：Claude Code / Codex / OpenCode / OMP / DeepSeek Harness。
4. 可以顺手填写第一条提示词，例如"帮我分析这个项目的结构"。
5. 点击创建，等待终端启动完成。

![新建会话对话框](guide-images/02-new-session.png)

## 在终端中与 Agent 对话

会话标签页内是一个完整的交互式终端，与在命令行里直接使用 Agent 完全一致：

- 直接输入文字，按回车发送。
- Agent 弹出的选择菜单、权限确认等都可以用方向键和回车操作。
- 终端尺寸会随窗口大小自动调整。

![会话终端运行中](guide-images/03-terminal.png)

> 提示：如果某个 Agent 命令不在系统 PATH 中，请到 **设置 → 通用** 的「Agent 可执行文件路径」里，按 Agent 分别填写可执行文件的完整路径；留空则自动查找 PATH。
