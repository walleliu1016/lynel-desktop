# 快速开始

Lynel Desktop 是跨平台的多 Agent 会话管理桌面应用：把 Claude Code / Codex / OpenCode / OMP 等终端 AI 助手装进一个本地窗口，用图形界面管理多个会话、随时查看运行状态，还能通过企业微信与手机 App 远程收发消息和处理授权。

## 界面总览

![主界面总览](guide-images/01-overview.png)

- **标题栏**：左侧显示正在运行的会话数量；右侧依次是使用指南、设置、退出登录和窗口按钮。点击关闭按钮不会退出程序，而是隐藏到系统托盘。
- **左侧栏**：顶部是收起按钮与云服务状态，下方是首页 / DeepSeek Harness / 搜索入口，中间是会话列表，底部是账户、使用指南与设置。
- **中间标签页**：首页、各个会话、设置、使用指南、DeepSeek Harness 分别以标签页打开；每个会话标签页内还有「**终端 / Trace**」两个子页。
- **会话子页**：切到「Trace」可查看该会话的 API 请求明细（状态、模型、延迟、费用、Token）。

## 使用哪个 Agent？

应用支持 **Claude Code / Codex / OpenCode / OMP** 四种 Agent。**默认只有 Claude Code 可用**；要使用 Codex / OpenCode / OMP，先到 **设置 → 通用** 打开对应的「Agent 启用」开关。**DeepSeek Harness** 是左侧栏的独立面板（需要先全局安装 dsh），不是会话 Agent。

## 创建第一个会话

1. 在首页输入第一条提示词，选择要使用的 Agent，回车即可创建；或点击「新建」打开新建对话框。
2. 选择工作目录（Agent 将在这个目录下工作）。
3. 可以顺手填写第一条提示词，例如"帮我分析这个项目的结构"。
4. 可选绑定一个企业微信机器人（见「企业微信集成」章节）。
5. 点击创建，等待终端启动完成。

![新建会话对话框](guide-images/02-new-session.png)

## 在终端中与 Agent 对话

会话标签页内是一个完整的交互式终端，与在命令行里直接使用 Agent 完全一致：

- 直接输入文字，按回车发送。
- Agent 弹出的选择菜单、权限确认等都可以用方向键和回车操作。
- 终端尺寸会随窗口大小自动调整；`Ctrl + 滚轮` 可调字号。

![会话终端运行中](guide-images/03-terminal.png)

> 提示：如果某个 Agent 命令不在系统 PATH 中，请到 **设置 → 通用** 的「Agent 可执行文件路径」里，为对应 Agent 填写可执行文件的完整路径；留空则自动查找 PATH。
